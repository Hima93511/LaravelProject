## About HealthGuard

HealthGuard is an Android-based health monitoring system designed to help users manage their medication schedules, ointment applications, and fitness goals through intelligent reminders and tracking.

Key features include:
- ⏰ Smart medication reminders with notification system
- 💊 Ointment application tracking
- 🏋️‍♂️ Fitness goal monitoring and progress tracking
- 🔔 Background scheduling with AlarmManager
- 📊 Dynamic health dashboard
- 🔄 Recurring reminder system

## Technology Stack

- **Frontend**: Android SDK, Kotlin, Jetpack Compose
- **Backend**: Laravel API (optional for cloud sync)
- **Database**: Room Database (local), MySQL (server)
- **Notification**: Firebase Cloud Messaging
- **Scheduling**: Android AlarmManager, WorkManager
